# 🌍 Overview

**Number1CV** is an AI-powered resume screening application that compares a candidate's resume with a job description using **Natural Language Processing (NLP)** and **Machine Learning techniques**.

The system extracts text from a PDF resume, analyzes its similarity with the provided job description, and generates a **Resume Match Score**.

Users can also enter required skills to identify:

- ✔ Matched Skills
- ✖ Missing Skills
- 📊 Required Skills Match Percentage

---

# ✨ Features

| Feature | Description |
|----------|-------------|
| 📄 PDF Resume Upload | Upload candidate resumes in PDF format |
| 📝 Text Extraction | Extract resume text using PyPDF2 |
| 💼 Job Description Matching | Compare resumes with job requirements |
| 📊 Resume Match Score | Calculate similarity percentage |
| 🤖 NLP Processing | Convert text into numerical features |
| 🧠 Machine Learning | Analyze resume-job similarity |
| ✔ Skills Analysis | Identify skills available in the resume |
| ✖ Missing Skills | Identify required skills not found |
| 📈 Skills Match Score | Calculate required skills percentage |
| 🌐 Interactive Dashboard | User-friendly Streamlit interface |
